# Angular

- Componentes standalone, signals para el estado local, `inject()` en vez de constructores largos.
- Servicios por funcionalidad con `HttpClient`; la URL del backend en `src/environments/`.
- Formularios reactivos tipados con validaciones.
- Lazy loading de rutas por funcionalidad.
- La verificación es `npm run build`. Si hay Chrome disponible, ejecuta también `npx ng test --watch=false --browsers=ChromeHeadless`.
