# React (Vite + TypeScript)

- Componentes funcionales y hooks; estado del servidor con TanStack Query; formularios con react-hook-form + zod.
- Rutas con React Router. Estructura por funcionalidad (`src/features/<x>/`).
- La URL del backend en `VITE_API_URL` (documentada en `.env.example`); un único cliente HTTP en `src/lib/api.ts`.
- Accesible: etiquetas en formularios, botones reales, contraste suficiente.
- Pruebas con Vitest + Testing Library (`*.test.tsx`).
